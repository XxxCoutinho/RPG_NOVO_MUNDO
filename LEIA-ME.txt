RPG Nexus — versão com cabeçalho padronizado e login obrigatório

Arquivos principais:
- index.html
- campanhas.html
- agentes.html
- ameacas.html
- homebrew.html
- login.html
- header.css
- firebase-config.js
- auth.js

O que foi ajustado:
1. Todas as páginas usam o mesmo cabeçalho compartilhado.
2. O menu contém: Início, Agentes, Campanhas, Ameaças, Homebrew e Login.
3. O botão de Login usa Firebase Authentication.
4. O login permite e-mail/senha e Google.
5. Ações de criação/adição agora exigem login antes de continuar.
6. A página campanhas agora usa o mesmo cabeçalho do projeto.
7. A paleta visual foi mantida consistente: fundo escuro, dourado como destaque e vinho para login/ações especiais.

Como testar:
1. Abra a pasta do projeto no terminal.
2. Rode:
   python -m http.server 8000
3. Acesse:
   http://localhost:8000

Observação importante:
Para o login com Google funcionar, ative o provedor Google no Firebase Authentication e mantenha localhost nos domínios autorizados do Firebase.
